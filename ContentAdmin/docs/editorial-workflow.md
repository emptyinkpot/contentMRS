# Editorial Workflow

ContentAdmin provides the human operation surface.

```text
1. Browse a work, chapter, article, source material, or EvidencePack.
2. Inspect topology and source coverage.
3. Edit draft fields in the admin UI.
4. Save through SDK/Gateway write facades.
5. Trigger ContentBase generation or review.
6. Read back generated body, trace, EvidencePack, and reviewer findings.
7. Approve, revise, or publish through controlled runtime actions.
```

The UI may show rich editors and graph views, but generated prose and canonical
records remain owned by their service boundaries.
