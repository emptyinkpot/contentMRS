# Support

This repository answers topology and recovery questions, not application feature questions.

## Before Asking

Identify which layer is involved:

- MySQL / CynosDB
- OpenList / Quark
- server filesystem
- MyBlog
- Mortis
- Sub2API
- code-server workspace
- local operator machine

## Provide

- Repository or system name
- Host or runtime path, if known
- Table, route, directory or consumer name
- Sanitized error message
- Whether the question is topology, recovery, schema, inventory or access

Do not provide live passwords, tokens, cookies, private keys or full dumps in routine support requests.
